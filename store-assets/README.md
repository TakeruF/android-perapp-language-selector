# Google Play store assets

This directory contains the source and exported assets used for the Google Play listing.

- `app-icon-source.png`: source artwork for the app icon
- `app-icon-512.png`: 512 x 512 store icon
- `app-icon-monochrome-source.png`: measured monochrome mask for Android themed icons
- `feature-graphic.svg` / `feature-graphic-1024x500.png`: 1024 x 500 feature graphic
- `phone-*.png`: 600 x 1200 phone screenshots
- `query-all-packages-demo.mp4`: 24-second reviewer video for the `QUERY_ALL_PACKAGES` declaration
- `review-video/*.svg`: editable caption panels used to build the reviewer video

The screenshots are derived from the real app. The current app icon uses the supplied generated artwork in `app-icon-source.png`.
